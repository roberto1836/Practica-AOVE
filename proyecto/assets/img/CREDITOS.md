# Créditos de las imágenes

Fuente y licencia de cada imagen del proyecto. Cada miembro del grupo añade aquí las suyas.

## Ilustraciones de productos (`productos/`)

- **Autoría:** propias del grupo (A, Noe). No proceden de bancos de imágenes ni de terceros.
- **Cómo se generan:** con el script `herramientas/generar-ilustraciones.mjs`, que lee `assets/js/datos/productos.js` y escribe un SVG por producto.
  - Ejecutar desde la raíz del repositorio: `node herramientas/generar-ilustraciones.mjs`.
  - El script está fuera de `proyecto/` porque no se despliega.
- **Licencia:** uso libre dentro de esta práctica.
- **Contenido:** solo formas geométricas (envase, etiqueta con un emblema de dos hojas de olivo, fondo y sombra). No llevan texto ni tipografías.
